**About the Repository**

Repository dedicated to organizing my studies using **Obsidian** as my primary knowledge management tool.

Here I concentrate my **study vaults**, organized by topic — from technology to learning new languages.

The repository was created by a Brazilian, but that doesn't mean it can only be used by fluent Portuguese speakers. Eventually, as my English fluency evolves, the vaults will also be written in English. Until then, there may be a language barrier — I apologize for that.

## 📥 Como Clonar o Repositório

Para baixar o repositório:

```bash
git clone https://github.com/SEU_USUARIO/Obsidian_Vaults.git
```

## Depois de clonar o repositório:

1. Abra o **Obsidian**  
2. Clique em **"Open folder as vault"**  
3. Selecione a pasta clonada

## 🤝 Como Contribuir

Embora seja um repositório pessoal de estudos, sugestões são bem-vindas.

### Para contribuir:

```bash
# Criar uma branch
git checkout -b minha-contribuicao

# Adicionar alterações
git add .

# Criar commit
git commit -m "Descrição da contribuição"

# Enviar para o GitHub
git push origin minha-contribuicao
```

Depois, abra um **Pull Request**.
